What you'll learn

Four modules across 12 weeks. Each module has nine live sessions and ends with a hands-on exercise, so every tool is used before you move on.

  1. Weeks 1–3

    Databases & SQL

    Learn how data is stored and how to ask databases the right questions.

    • Relational database concepts
    • SELECT, WHERE and ORDER BY
    • Aggregations and GROUP BY
    • JOINs across tables
    • Subqueries and CTEs
    • Cleaning data with SQL
  2. Weeks 4–6

    Python, Excel & VBA

    Clean, transform and automate your analysis with scripting and spreadsheet power tools.

    • Python basics for analysts
    • pandas for data wrangling
    • Advanced formulas and PivotTables
    • Power Query
    • VBA macros and automation
    • Exploratory data analysis
  3. Weeks 7–9

    ETL with Alteryx

    Build repeatable workflows that extract, transform and load data without manual rework.

    • ETL concepts
    • Connecting to multiple data sources
    • Data preparation and blending
    • Building and scheduling workflows
    • Data quality checks
  4. Weeks 10–12

    Tableau & Power BI

    Turn analysis into interactive dashboards and a clear story for decision-makers.

    • Visual design principles
    • Charts, maps and KPIs
    • Interactive dashboards
    • DAX and calculated fields
    • Data storytelling

Capstone project

In the final weeks you take a real dataset from raw files to a finished dashboard, using SQL, Python or Excel, Alteryx and a BI tool, then present your findings.

No. The programme starts from the basics. If you are comfortable with a computer and basic spreadsheets, you can join.

Yes. The programme is designed for working professionals: three live one-hour sessions a week, plus a few hours of practice. Session times are confirmed by email before the start date.
